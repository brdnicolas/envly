# @envly/web

Envly website and REST API (Next.js 16, Prisma 7, Neon Postgres), deployed on Vercel (Root Directory: `apps/web`).

```bash
yarn dev             # from the repo root → http://localhost:3000
yarn db:migrate      # create/apply a migration
```

Docs: [architecture](../../docs/architecture.md) · [deployment & env vars](../../docs/deployment.md)
